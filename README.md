## Install on Android

1. Download **MyPersonalKodi-Android.apk** on your phone, or copy it to your Android TV.
2. Open the file. Allow installation from your browser or file manager if Android asks.
3. Choose **Install**, then open **MyPersonalKodi**.

Requires Android 7 or later. The same file works on phones and Android TV.

## Install on Windows

1. Download **MyPersonalKodi-Windows.zip**.
2. Right-click the ZIP and choose **Extract All**.
3. Open the extracted folder and double-click **my_personal_kodi.exe**. Keep the other files in that folder.

## Join your family

1. Ask your family owner for the sync service address.
2. Open the app, enter that address and choose **Join my family**.
3. Give the code on your screen to the owner. On their connected device, they open **Settings > Devices > Add a device** and enter your code.
4. Choose your profile once the device is approved.

The owner connects Real-Debrid and TorBox for the family. Each profile can connect its own MDBList account.

## Update the app

From version 1.1.6, the app checks for a newer version when it starts. Choose **Update now**, or open **Settings > Check for updates**. Android asks you to confirm installation and may ask you to allow updates from MyPersonalKodi. Windows restarts to finish installing.

For older versions, or if the automatic update cannot finish, use the downloads above:

- **Android:** install the new APK over the existing app. Do not uninstall first if you want to keep its saved setup.
- **Windows:** close the app, extract the new ZIP into a new folder and run it from there.

iPhone and iPad downloads are not available yet.
